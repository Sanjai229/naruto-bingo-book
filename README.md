# Naruto Bingo Book

An interactive Naruto and Naruto Shippuden fan website: a living world map, character dossiers, organisations, tailed beasts and a jutsu ranking.

- Character pictures are fan art made for this site.
- The opening video plays through YouTube's own player.
- Naruto and all related names belong to Masashi Kishimoto, Shueisha and Studio Pierrot. This is an unofficial fan project.

To change the intro video, open `index.html`, search for `INTRO_VIDEO_ID` and put in the id from a YouTube link (the part after `watch?v=`).
